# 完整案例

按所需研究传统选读。第一例来自公开研究及访谈，后两例是教学设定，其中的观察和资源仅为给定条件。

## 崔潇濛的农业适应研究

### 可回查的原材料

2017 年简历把美国作物种植面积响应列为求职论文，同时列出单产长期适应的在研项目。2019 年简历并列面积、弃收和模型选择工作论文，说明多条研究线已有并行基础。[2017 年简历](https://arefiles.ucdavis.edu/uploads/filer_public/6b/df/6bdfceef-e333-4cb1-baba-d459e671a5ef/cui_cv.pdf) · [2019 年简历](https://iesr.jnu.edu.cn/_upload/article/files/54/c3/95093a1f4a14a324f726d9606439/c8bbb7d3-f1a4-4850-90c7-87724fb9197d.pdf)

2020 年两篇论文分别研究作物种植布局和播种后的收获决定。2022 年生长季论文导言明确将播种日期与生长季研究视为对既有作物选择、种植和收获研究的补充。[种植布局论文](https://doi.org/10.1016/j.jeem.2020.102306) · [弃收论文](https://doi.org/10.1086/709859) · [生长季论文导言](https://doi.org/10.1111/ajae.12227)

东北农户研究观察高温、农业收入和消费，作者解读认为现金与粮食库存能够缓冲当期消费。2024 年访谈进一步明确提出，连续受灾时资产能否继续维持消费值得研究。[农户论文](https://doi.org/10.1016/j.jdeveco.2023.103243) · [作者解读](https://voxdev.org/topic/energy-environment/how-do-rural-households-china-adapt-extreme-heat) · [访谈印刷页 30](https://iesr.jnu.edu.cn/_upload/article/files/75/af/befbad5f493baac4e6256a79f02c/6ce4f758-0ef1-4ebd-948f-351d659618a6.pdf)

生长季论文讨论指出，品种改良可能改变可调整空间，当时缺少育种与品种采用数据。2024 年访谈印刷页 31 将水利设施和育种激励列为正在推进的方向。这支持从观察适应行为到研究适应条件的联系。[生长季论文讨论](https://doi.org/10.1111/ajae.12227) · [2024 年访谈](https://iesr.jnu.edu.cn/_upload/article/files/75/af/befbad5f493baac4e6256a79f02c/6ce4f758-0ef1-4ebd-948f-351d659618a6.pdf)

### 一张问题接续卡

| 字段 | 示例 |
| --- | --- |
| 原研究依据 | 一次高温冲击后，农户利用现金和粮食库存缓冲消费，见农户论文与作者解读 |
| 仍待解释之处 | 对一次事件的证据尚不能说明连续受灾后的缓冲是否可持续 |
| 下一研究问题 | 连续高温冲击是否削弱农户重新建立储蓄与粮食库存的能力，并改变其消费与生产选择？ |
| 承接理由 | 将单次应急扩展到重复冲击下资源消耗与恢复的过程，延续对家庭生计的关注 |
| 潜在贡献 | 识别缓冲的持续条件。该候选的当前文献位置仍需核查 |
| 竞争解释 | 持续消费下降可能来自资产耗竭，也可能来自其他收入渠道同时受损 |
| 材料与路径 | 需要多年家庭资产、库存、收入与消费记录及相应天气暴露。能否取得这些材料尚需确认，并核对冲击时序、其他渠道及样本流失 |
| 改变判断的依据 | 若资产可以恢复且消费差异主要对应其他收入变化，需要修改以耗竭为中心的解释 |
| 优先级与下一步 | 先核查重复冲击研究，并确认能否跟踪同一家庭的库存与资产恢复 |

访谈明确提出重复受灾问题，连接身份为“作者直接说明”。卡片中对恢复能力、竞争解释和材料的细化属于本次建议，并不据此认定已有对应的后续成果。

### 研究网络和取舍

可归纳的持续关切是，环境变化以后，人的选择如何改变农业及生计后果。种植、收获和播期分别观察选择，家庭研究考察生活水平，育种与水利考察适应条件。前述原文支持这些知识联系。

“换一个地区再看高温对消费”只有在该地区的保险、金融或家庭支持会改变机制时，才有明确的延伸理由。仅增加结果指标仍需解释该指标改变了什么判断。新工作论文的投稿状态应在用户确实需要时重新核查。

## 教育社会学中的支持与求助

### 给定材料

假设用户的一项研究发现，大学预警通知后学生咨询次数增加，但第一代大学生的咨询变化较小。用户拥有通知及预约记录，可在本校开展访谈，尚无跨校资料。以上均为教学设定。

持续关切可写为，学校提供的支持如何被不同学生理解并转化为实际帮助。

### 候选一

| 字段 | 示例 |
| --- | --- |
| 原研究依据 | 通知与预约记录显示群体差异，记录尚未呈现学生收到通知后的理解过程 |
| 仍待解释之处 | 较少预约可能来自信息未被接收、服务不可及、通知被理解为能力审判，或已有其他支持 |
| 下一研究问题 | 学生如何理解预警通知，并在什么互动环节形成求助或回避的决定？ |
| 承接理由 | 拆开收到通知到实际求助的过程，解释原研究中的差异 |
| 潜在贡献 | 揭示服务分类、组织接触与学生自我理解的关系，相关研究仍需检索 |
| 竞争解释 | 污名预期、时间冲突、信息缺失和其他支持可能分别导致较少预约 |
| 材料与路径 | 从已预约、未预约及不同通知经历中选择访谈对象，结合通知文本、预约过程和服务时间，追踪行动者的解释及反例 |
| 改变判断的依据 | 若回避者已充分理解且愿意求助，实际障碍主要是服务排期，需要修改以污名为中心的解释 |
| 优先级与下一步 | 优先核对预约指标能否反映真实求助，再进行可行性访谈 |

### 候选二和取舍

可进一步研究学院的回应方式怎样影响学生把预警视为支持或评价。需要先确认同校学院间是否存在可观察的回应差异。跨校比较暂缓，因为用户尚无跨校材料。若第一项研究发现组织互动关键，第二项可以围绕互动差异展开。若主要障碍是时间冲突，则转向服务安排。

“第一代学生不重视求助”应作为需要证据的解释。咨询次数和支持是否充分、生活是否改善之间还需要对应材料。

## 规范研究中的行政决定解释义务

### 给定论证

假设用户已经论证，影响个人重要利益的行政决定应当向当事人提供可理解的理由，理由有助于质疑和纠错。用户希望继续研究自动化决定，现有材料是哲学与公共行政文献和构造案例。此处讨论规范主张，具体法律义务需要另行核查。

持续关切是，公共权力怎样通过给出理由，使受影响者能够有效质疑决定。

### 一张问题接续卡

| 字段 | 示例 |
| --- | --- |
| 原研究依据 | 原论证以可理解理由支持个人质疑行政决定 |
| 仍待解释之处 | 自动化决定可能只能得到统计解释、模型过程说明或人工复核理由，这些解释与可质疑性的关系有待辨明 |
| 下一研究问题 | 对自动化行政决定，什么样的理由能够满足有效质疑的要求，其义务强度应如何随影响程度与可纠错性变化？ |
| 承接理由 | 检查原原则在自动化条件下的概念边界和实现条件 |
| 潜在贡献 | 澄清可理解性、可质疑性与解释义务的关系，文献定位待核查 |
| 论证张力 | 理由的个体针对性与公开解释的成本、公平性及其他正当利益之间可能冲突 |
| 材料与路径 | 重构原论证，比较个案理由、一般程序说明和复核安排，构造解释清楚但无法质疑、解释有限但能有效纠错等边界案例 |
| 改变判断的依据 | 如果某种程序在缺乏个体理由时仍充分保障质疑，需要修正理由与可质疑性的必要关系 |
| 优先级与下一步 | 先明确“理由充分”的判断标准，检索程序正义和解释义务的最强异议 |

### 延伸与取舍

若进一步研究公众如何理解理由，经验材料可以检验实现条件。公众偏好本身仍需与义务的正当性论证衔接。单纯更换决定领域时，说明利益性质或纠错条件为何改变原则的要求，才能形成具体贡献。

这一例的结果可以是经修订的原则、适用条件和回应反驳。研究路径随论证目标选择。
