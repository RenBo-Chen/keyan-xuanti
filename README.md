# 科研选题

从已有论文、研究发现或理论命题出发，发展有实质联系的后续问题，并逐步构建长期研究议程。

显示名称为“科研选题”，内部调用名为 `keyan-xuanti`。

仓库地址为 [RenBo-Chen/keyan-xuanti](https://github.com/RenBo-Chen/keyan-xuanti)。

## 适用场景

- 已完成一篇论文，希望确定下一篇研究什么。
- 手中有若干发现，需要找到值得继续解释的现象、机制或边界。
- 已有多个研究方向，希望梳理其联系与推进优先级。
- 分析一位学者的研究体系，并区分公开记载与分析者归纳。

## 工作方式

本 skill 保留一条可以检查的推理链。

**已有研究回答了什么 → 什么仍需解释 → 下一问为什么成立 → 怎样取得证据或完成论证 → 答案将怎样推进原有理解。**

适用于经验研究、过程与解释研究、历史与比较研究，以及规范和概念研究。研究问题决定材料与方法，可以使用统计数据、访谈、观察、文本、档案、比较案例或理论论证。

## 提供什么材料

可提供论文全文、摘要、主要结果、已有理论论证或研究笔记，并说明学科方向、可用材料和时间条件。只有初步材料时，skill 会标明当前判断的依据与待核查事项。

## 获得什么结果

- 一句能够长期追问的核心关切。
- 已有研究中的具体延伸位置。
- 少量有联系的候选问题及筛选理由。
- 重点问题的“问题接续卡”，包括原研究依据、承接理由、潜在贡献、竞争解释或论证张力、材料路径与下一步。
- 问题之间的承接、分叉、并行及相互修正关系。

## 安装与调用

在支持 `skill-installer` 的环境中选择该技能，可以使用下面的安装请求。

## 文件结构

```text
keyan-xuanti/
├── README.md
├── SKILL.md
├── agents/
│   └── openai.yaml
└── references/
    ├── question-moves.md
    └── worked-examples.md
```

`SKILL.md` 包含核心流程与输出要求。`question-moves.md` 展开问题延伸办法。`worked-examples.md` 包含农业适应、教育社会学和规范研究三个案例。`agents/openai.yaml` 设置显示名称和默认调用提示。

## 方法来源

本 skill 根据崔潇濛的论文及公开访谈归纳研究问题之间的联系，并将这些思路转化为跨社科工作流程。原始来源见 `references/worked-examples.md`。其中，崔潇濛案例有公开来源，教育社会学与规范研究案例为已明确标记的教学设定。

对学者研究脉络的分析会区分“作者直接说明”“论文内容支持”和“分析性推演”。候选问题的文献贡献与材料可得性分别核查，并保留核查状态。
